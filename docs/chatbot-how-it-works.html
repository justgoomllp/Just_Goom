How the Just Goom AI chatbot will work

A help assistant for system questions: register, plans, inquiries, verification, and agents. It answers only from an admin-managed FAQ. Open this file in a browser and try the demo on the right.

1. What it is

Help bot

Answers “How do I list my business?” and “What is Gold plan?” It is not live chat with a company, and not a ticket desk.

Who sees it

Floating widget on the public site (home, about, contact, pricing) and on business/agent dashboards. Not in admin.

Where answers come from

Admin FAQ rows + a short system brief (prices, contact). If it does not know, it sends the user to Contact.

2. How a question is answered

User types in widget → POST /chatbot/ask → Load active FAQs → LLM writes the reply → Show answer + save log
1

Widget sends the message

JSON: message + session id. CSRF token is required. Max about 1000 characters. Rate limit: 10 per minute per IP.

2

Server builds a strict prompt

Active FAQ text + last 6 turns. Role is only guest / user / agent. No passwords, inquiries, or payment data.

3

LLM answers or escalates

Uses OpenAI or Groq (API key stays on the server). Unknown topics: “I don’t have that — contact us.”

My Team — how to fill

Log in → My Team → Add Member. Shows on the public profile immediately.

  • * Full Name (max 150)
  • * Designation / Role (max 150)
  • * Email
  • * Phone — exactly 10 digits
  • Department — Sales, Operations, Wholesale, Customer Support, Management, or type Other
  • Profile Photo — optional, max 2 MB
  • Bio / Responsibilities — optional, max 5000
  • Checkbox: Show as primary contact on public profile

Services & Products — how to fill

Same Add form. Choose Type. Filter list: All / Services / Products.

  • * Type — Service or Product
  • * Name (2–200 characters)
  • Short Description — max 5000
  • Price — e.g. 1500, 1500.00, or 1500+
  • Image — JPG/PNG/WEBP/GIF, max 2 MB
  • Quota is shared: products + services together

My Documents — how to fill

GST, BIS, certificates, catalogues on the public profile.

  • * Document Name (2–200)
  • * Document Type — PDF, Word, or Excel (file must match the type)
  • * File — PDF/Word/Excel max 5 MB
  • You can later toggle status on the list

My Listings — how to fill

Menu label is My Listings for real estate / engineering; otherwise My Projects.

  • Property listing: * Title, * Price, * Location, * listing images (up to 12). Optional: description, EMI, configuration (3 BHK), sale type, possession, parking, amenities, brochure URL
  • Engineering listing: * Title, * Price / Quote, * Location / Site, * images. Optional: price note, service type, industry, lead time, capacity, features, brochure URL
  • Normal project: * Title, * Type (Document / Video / Link), file or URL, optional thumbnail

My Articles — how to fill

Dashboard → My Articles → Write New Article.

  • * Article Title (max 300)
  • * Article Content
  • * Status — Draft or Published (publish sets the public date)
  • Featured Image — optional cover, max 2 MB

My Videos — how to fill

Dashboard → My Videos → Upload Video. Provide a link or a file.

  • * Video Title (max 200)
  • External Video URL — YouTube, Vimeo, etc. or
  • Upload Video File — MP4, AVI, MOV, WMV, WebM (plan max, usually 5 MB)
  • Thumbnail Image — optional, 2 MB (useful for reel-style links)

My Offers — how to fill

Dashboard → My Offers → Create Offer. Homepage shows Active + date range includes today.

  • * Offer Title (max 200)
  • * Start Date — today or later on create
  • * End Date — on or after start
  • Description — max 2000
  • Banner Image — max 2 MB
  • Link URL — optional https://…
  • On edit: Status Active or Paused

Locked menus?

If the sidebar shows a lock, buy Silver / Gold / Platinum first (Subscription). Profile, subscription, payments, activity log, password, and notifications stay open without a plan.

6. What it will and will not do

Will

  • Answer how Just Goom works
  • Quote published plan prices and limits
  • Point unknown questions to Contact
  • Keep a short conversation memory (last 6 turns)
  • Log chats so the FAQ can improve

Will not (v1)

  • Chat buyer ↔ company
  • Read inquiries, invoices, or documents
  • Change plans or create tickets
  • Search all articles with RAG
  • Appear in the admin panel
